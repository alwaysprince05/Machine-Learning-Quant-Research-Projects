# Multi-Factor Alpha Landscape Explorer

An advanced machine learning and quantitative research platform for exploring synthetic alpha factors and their predictive relationships.

## Features
- Synthetic financial market data generation
- Alpha factor engineering (momentum, volatility, mean reversion, liquidity imbalance, synthetic sentiment, order flow pressure)
- ML regression for future return prediction
- Feature importance analysis
- Dimensionality reduction (PCA, t-SNE)
- Alpha decay and signal instability simulation
- Institutional-style quant dashboard (dark mode, Bloomberg/Two Sigma style)
- Advanced visualizations: feature importance, scatter plots, error distributions, heatmaps, 3D landscapes, PnL/Monte Carlo simulations

## Installation
```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn
```

## Usage
```bash
python multi_factor_alpha_landscape_explorer.py
```

## Notes
- Fully synthetic data only
- For educational/research use
- No real trading execution
