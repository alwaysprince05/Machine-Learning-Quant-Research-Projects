## 📁 Projects Included

---

### 1. 💧 Liquidity Shock Simulator

#### Overview

A quantitative market microstructure simulation project focused on liquidity crises, spread expansion, execution pressure, and volatility stress events.

#### Features

- Synthetic order book generation
- Bid/ask liquidity depth modeling
- Spread widening simulations
- Liquidity imbalance analysis
- Machine learning regression models
- Monte Carlo stress scenarios
- 3D liquidity surface visualization
- Correlation heatmaps
- Feature importance analytics
- Predicted vs actual ML diagnostics
- Simulated PnL analysis

#### Technologies

`Python` · `NumPy` · `Pandas` · `Scikit-Learn` · `Matplotlib` · `Seaborn` · `SciPy`

#### Run

```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn
cd "Liquidity Shock Simulator"
python liquidity_shock_simulator.py
```

### 2. 🧬 Neural Regime Detection Engine

#### Overview

An AI + quantitative finance project that detects synthetic market regimes such as trends, crashes, panic states, and volatility transitions using machine learning and probabilistic modeling.

#### Features

- Synthetic market regime generation
- Regime clustering models
- Gaussian Mixture Models (GMM)
- PCA dimensionality reduction
- Volatility-state transitions
- Confidence score mapping
- Hidden-state style analytics
- 3D volatility-regime visualizations
- Transition heatmaps
- Monte Carlo regime simulations

#### Technologies

`Python` · `NumPy` · `Pandas` · `Scikit-Learn` · `Matplotlib` · `Seaborn` · `SciPy`

#### Run

```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn
python neural_regime_detection_engine.py
```
